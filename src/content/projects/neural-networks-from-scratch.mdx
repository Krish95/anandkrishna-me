A multi-layer neural network implemented from first principles in Python, using
only NumPy — no autograd, no framework.

- **97%** accuracy on MNIST and **58%** on a Cat–Dog dataset.
- Implemented and compared several activation functions; **Swish** outperformed
  ReLU by 0.5 percentage points on MNIST.
- Performance comparable to equivalent Keras implementations, which was the point:
  the exercise was to show the framework isn't doing anything mysterious.
