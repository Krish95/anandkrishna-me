A facial image reconstruction and recognition system built on **Eigenfaces**,
using Principal Component Analysis.

- **96%** classification accuracy on the Olivetti faces dataset.
- Tuned the dimensionality reduction to hold reconstruction fidelity while
  keeping the computation cheap — the whole trade-off in Eigenfaces is how many
  components you can afford to throw away.
